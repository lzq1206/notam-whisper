# 中国及周边火箭动态小组件

- 预览页：`https://rocket.rainywhisper.com/widget/`
- 网页地图预览图：`https://rocket.rainywhisper.com/widget/china-square.png`
- 小号 ScriptWidget 包（169×169 pt，@2x，338×338 px）：`https://rocket.rainywhisper.com/widget/china-rocket-map-small.swt`
- 大号 ScriptWidget 包（360×376 pt，@2x，720×752 px）：`https://rocket.rainywhisper.com/widget/china-rocket-map-large.swt`
- 两个包分别固定支持 ScriptWidget 的 `systemSmall` / `systemLarge`，不能自动切换尺寸。按准备添加的 iOS 主屏幕组件尺寸导入对应包。
- 小组件图片每 3 小时服务端重绘；iOS 实际刷新时点由系统调度。
- 渲染图片不叠加生成日期。Esri World Imagery 的地图来源署名根据服务条款保留在地图右下角。
